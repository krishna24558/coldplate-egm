# Possible future extensions

Ideas that build on this project but are outside the MEEN 615 scope (see `docs/project_scope.md`). Not part of the course deliverables.

## 1. Thermo-mechanical warpage of a bi-material die/substrate strip

For example, use COMSOL Heat Transfer + Solid Mechanics on a bi-material die/substrate strip, and check its warpage against the Timoshenko bimetal analytical solution. Then add a Python parameter sweep over CTE mismatch and thickness ratio. That's about a weekend of work, and it feeds the MEEN 689 term paper. It would give a real "thermo-mechanical, warpage, validated" project bullet; write the resume bullet from the actual results once it is built.
